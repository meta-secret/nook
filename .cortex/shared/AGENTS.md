# Shared Knowledge Contract

Shared Cortex is a cross-team reference surface. It is not an implementation
team.

## Load boundary

Load [the shared knowledge graph](knowledge-graph.md) only when the assigned
task names a cross-team architecture, catalog, reference, or engineering rule.

- Open only the named shared document.
- Do not scan the entire shared tree.
- Return to the selected team graph after resolving the dependency.
- Do not use shared placement to erase a clear team owner.

## Write boundary

Team agents may propose a shared-document correction.

The delivery owner decides the canonical owner and serializes the edit. Shared
documents must not become a shortcut for one team to change another team's
policy.

## Validation

Every shared document must be indexed by the shared graph and must serve at
least two teams or a repository-wide contract.
