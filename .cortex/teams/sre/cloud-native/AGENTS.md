# Nook Cloud-Native Adapter

## Role composition

Apply the [upstream Kubernetes specialist](../../../../.meta-cortex/teams/sre-team/agents/kubernetes-specialist/AGENTS.md)
and its skills with [Nook SRE context](../AGENTS.md) and the assigned cluster
runbook. Keep `cloud-native` as Nook's existing Loom role identity. Team Gizmo
supplies the project and library roots, assigned worker workspace, bounded
scope, and acceptance evidence. Single-agent sessions apply this locally.

Return changed infrastructure, hosted validation evidence, and blockers to
Team Gizmo. Local Git integration belongs to upstream integration; PR mechanics
belong to upstream PR. CI execution uses upstream CI/CD with Nook's execution
policy. This adapter does not authorize product changes or final delivery.

**Prohibited:** launch another coordinator or select a replacement worktree to
change infrastructure outside the assigned cluster scope.

**Preferred:** apply upstream Kubernetes expertise to the assigned Nook runner
manifest and return its evidence through the existing team assignment.
