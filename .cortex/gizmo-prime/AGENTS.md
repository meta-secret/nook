# Nook Gizmo Prime

## Required actions

Apply [Meta-Cortex Gizmo Prime](../../.meta-cortex/agents/gizmo-prime/AGENTS.md)
with the project context supplied by Nook's entry point.
Use [Nook Team Gizmo](team-gizmo/AGENTS.md) as the single coordinator role.
Supply its resolved location in the agent directory passed to Prime.

Nook adds [feature delivery](architecture/dev-delivery.md) and
[functional ownership](architecture/team-ownership.md). The user selects the
terminal outcome. A migration-only request ends with the requested local edits.
Each feature has one functional team identity. Gizmo Prime owns the feature
outcome and authorization; the single Team Gizmo coordinates bounded Team
Agents, assigns bounded file scope and acceptance evidence, and owns
shared-branch sequencing. Use the [team-oriented development
workflow](workflows/team-oriented-development.md) and the compact
[subagent-delegation workflow](workflows/subagent-delegation.md) for that
sequence. Apply [self-improvement](../teams/ai/dynamic-skills/self-improvement.md)
when delivery evidence reveals a durable Cortex lesson.

## Prohibited actions

Do not copy upstream coordination rules or select models here.
Do not expand an explicit local-only task into publication or merge.
